# Turkey Trot tracker

A live race page for a small group of runners: GPS dots on a map, mile splits, and a cheer wall for family.

- Hosted on GitHub Pages; live data in Firebase Realtime Database (anonymous sign-in).
- `database.rules.json` holds the security rules pasted into the Firebase console.
- Open the site with no `?r=` to create a race; share the `?r=...` link it gives you.
